# Simple Accounting System

A simple accounting system built with Java and designed to run through a command-line interface (CLI).

## Overview

This project provides a foundation for managing accounting-related tasks from a terminal. It is intended to be simple, lightweight, and easy to run in a Java development environment.

## Requirements

- Java Development Kit (JDK) 8 or later
- A terminal or command prompt
- Git, if you are cloning the repository

## Getting Started

### Clone the repository

```bash
git clone https://github.com/IceSage01-cy/Simple-Accounting-System.git
cd Simple-Accounting-System
```

### Compile the project

Compile the Java source files using your preferred Java compiler. For example:

```bash
javac *.java
```

If the source files are organized in packages or directories, compile them according to the project structure.

### Run the application

Run the class containing the `main` method:

```bash
java Main
```

Replace `Main` with the actual entry-point class name if it differs.

## Usage

Start the application from a terminal and follow the prompts displayed by the command-line interface.
